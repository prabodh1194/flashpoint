Serverless Spark Connect on AWS

Flashpoint runs Apache Spark on AWS with no cluster to manage. A warehouse is a driver and its executors on ECS Fargate, reached over Spark Connect; you run SQL in a worksheet and every query renders as a profile, operator tree, per-node time, rows in and out. Tables live on Iceberg in S3. It is early software: run the quickstart on your laptop, or join the waitlist for a hosted try-it.

01How it works

A warehouse is launched on demand, exposes one Spark Connect gRPC endpoint, and suspends itself when idle. The gateway is stateless: every read and write goes through DynamoDB, so two gateway instances agree on the same state and a restart changes nothing.

↗Spark Connect

Stock Apache Spark Connect as the client protocol, with no fork. A warehouse returns a sc:// endpoint any Spark Connect client can reach. SQL clients go through the gateway.

gRPCno fork

▦Driver + executors

One on-demand driver (4 vCPU / 16 GB) plus n spot executors (2 vCPU / 8 GB each). T-shirt sizes map to executor count, so XS is a driver and one executor.

ecs fargatespot executors

◫Tables on S3

Iceberg tables on S3 with a Glue catalog. Query results are written as Parquet to S3 and expire after seven days; query records live in DynamoDB with a TTL.

icebergglue

◔Metered and reaped

Compute-seconds are metered from the moment a name is claimed. A background reaper suspends warehouses past their idle TTL, so an abandoned warehouse stops billing by itself.

per-secondauto-suspend

03The UI

Five views, each with a reload-safe URL: a SQL worksheet, the query-profile DAG, a warehouse manager, a data explorer, and a cost center. They are one product, not a dashboard bolted onto a notebook.

▤Worksheet

Type SQL, get columns and rows. Sync queries are deadline-bounded, and resubmitting the same SQL on the same warehouse is a cache hit rather than a rerun.

◔Query profile

An operator tree parsed from the stock Spark UI REST API: per-node duration, share of execution time, rows in and out, skew and spill flags.

▦Warehouse manager

Create, suspend, resume and resize. Sizes are T-shirt sizes over executor count, and a suspended warehouse costs nothing.

$Cost center

Every resource with its state, uptime and monthly estimate, daily spend from Cost Explorer, live per-warehouse meters, and a projection against a monthly budget.

04Spark SQL UI, explained

The stock Spark UI is a job tracker. It is built for a cluster operator: jobs, stages, tasks, environment and executors, served on port 4040 for as long as the driver lives. It answers "is the job running?" well, and "why was this query slow?" only indirectly.

A warehouse-shaped UI answers the second question first. The differences that matter:

  • SQL-centric, not task-centric. A query becomes an operator tree (scan, filter, join, aggregate, exchange) instead of a stage list you have to translate.
  • Per-node cost. Each operator shows its share of total execution time, color-heated, so the expensive node is visible without reading a table.
  • Column treatments. Filters and projections are summarized per node, so you can see what happened to the columns you selected.
  • Skew and spill flags. A node that spilled to disk or ran with one oversized task is marked, not left for you to infer.
  • A reload-safe URL. Every profile is addressable, so a query profile can be pasted into a review or an issue.

All of it is grown from the stock Spark UI REST API, with no fork and no agent inside the driver.

05What it is not

  • Not finished. It is early software. Treat it as a working prototype of the loop, create a warehouse, run SQL, read the profile, pay for compute.
  • No auth or multi-tenancy yet. Identity, per-user isolation and per-user quotas are the current milestone (Forge). Until they land, a hosted try-it is global and capped, not per-account.

06FAQ

Is Spark Connect the same as Databricks Connect?

No. Spark Connect is the upstream Apache Spark protocol, available in the Spark distribution. Databricks Connect is a client for Databricks. Flashpoint speaks stock Spark Connect, so a standard Spark Connect client can point at a warehouse endpoint.

Do I need a cluster?

No. You create a warehouse; the gateway launches an on-demand driver and spot executors on ECS Fargate, waits for the driver to be ready, and returns a Spark Connect endpoint. When the warehouse is idle it suspends and costs nothing.

What does it cost?

You pay only for compute while a warehouse is running. Suspending drops a warehouse to zero. Compute is metered per compute-second, and the Cost Center shows daily spend and a monthly projection. The hosted try-it pilot is budget-capped per session.

Does it work with pandas and notebooks?

Spark Connect has clients for PySpark and other languages, and the endpoint is a normal Spark Connect endpoint, so notebook and DataFrame code can connect directly. The gateway's REST API is the control plane and the SQL path.

Is there a free tier?

Not yet. The hosted try-it pilot is invite-only and hard-capped to a monthly budget. You can run the whole stack yourself on your laptop with the quickstart, or deploy it to your own AWS account.
